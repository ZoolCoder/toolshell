# Code of conduct

## Expected

- Be kind and direct. Critique the code or the idea, not the person.
- Assume good faith, and ask before assuming a mistake.
- Remember that many contributors work in a second language.

## Not accepted

- Harassment, discrimination, personal attacks, or unwelcome attention in
  any project space.
- Publishing someone's private information.

## Enforcement

Report to abdallah.coder@gmail.com with "toolshell conduct" in the subject.
Reports are read by the maintainer, kept confidential, and answered within
7 days. Consequences range from a warning to removal from the project
spaces.

This document is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
